## 📂 What's in this folder

| Folder / File | Contents |
|---|---|
| `Notes/` | Concept notes — e.g. `SQL-Operators.pdf` |
| `Task/` | Session-wise practice tasks assigned during live classes, solved as Jupyter notebooks (queries run via a MySQL connection) |
| `Task/Datasets/` | Raw datasets (CSV) used across the tasks |
| `Dataset/S32`–`S37` | Datasets organized by session number, matching each task notebook |
